# Universal Identity

**Ein modernes Identitäts- und Dokumentensystem für FiveM QBCore-Server.**

Universal Identity bietet eine zentrale Verwaltung von Identitäten, Ausweisen und Lizenzen sowie ein integriertes Polizei- und Administrationssystem.

## Funktionen

- Verwaltung verschiedener Ausweise und Dokumente
- Personalausweis mit Spielerfoto
- Dienstausweise und Waffenscheine
- Angel-, Piloten- und Bootsführerscheine
- Individuell platzierbare Fotostationen
- Personalausweis-Abholstationen
- Integriertes Polizei-System
- Mitarbeiterverwaltung und Stellvertretung
- Administrations-Tablet
- Konfigurierbare Berechtigungen und Einstellungen

## Voraussetzungen

- FiveM Server
- QBCore
- oxmysql
- screenshot-basic
