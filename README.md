# Universal Identity

**Ein modernes Identitäts- und Dokumentensystem für FiveM QBCore-Server.**

Universal Identity bietet eine zentrale Verwaltung von Identitäten, Ausweisen und Lizenzen sowie ein integriertes Polizei- und Administrationssystem.

## Funktionen

- Verwaltung verschiedener Ausweise und Dokumente
- Personalausweis mit Spielerfoto
- Dienstausweise und Waffenscheine
- Angel-, Piloten- und Bootsführerscheine
- Individuell platzierbare Fotostationen
- Personalausweis-Abholstationen
- Integriertes Polizei-System
- Mitarbeiterverwaltung und Stellvertretung
- Administrations-Tablet
- Konfigurierbare Berechtigungen und Einstellungen

## Voraussetzungen

- FiveM Server
- QBCore
- oxmysql
- screenshot-basic

## Installation

1. Lade die aktuelle ZIP-Datei aus dem Bereich **Releases** herunter.
2. Entpacke das Archiv.
3. Kopiere den Ressourcenordner `universal_identity` in deinen FiveM-Server unter `resources`.
4. Stelle sicher, dass die benötigten Abhängigkeiten installiert und gestartet sind:
   - `qb-core`
   - `oxmysql`
   - `screenshot-basic`
5. Folge der mitgelieferten Installationsanleitung `INSTALLATION_QBCORE_DE.txt`.
6. Trage `ensure universal_identity` in deine `server.cfg` ein. Die Abhängigkeiten müssen vorher gestartet werden.
7. Starte deinen Server neu und kontrolliere die Serverkonsole auf Fehlermeldungen.

## Updates

Vor jedem Update solltest du deine Resource-Dateien und Datenbank sichern.

Beachte die Datei `UPDATE_SYSTEM_DE.md` im Downloadpaket für weitere Hinweise zum Aktualisieren.

**Wichtig:** Die optionale SQL-Datei zur Bereinigung von Testdaten darf nicht bei einer normalen Installation oder einem Update ausgeführt werden.
